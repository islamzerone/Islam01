Islam01.Ai — Vercel setup\n\n1. Import this repository in Vercel.\n2. In Vercel Project Settings > Environment Variables add OPENAI_API_KEY with your OpenAI API key (Production and Preview as needed).\n3. Optional: set OPENAI_MODEL=gpt-6-luna.\n4. Redeploy the project.\n5. Test POST /api/islam01-ai.\n\nNever put the API key in index.html or browser code. OpenAI API billing is separate from a ChatGPT subscription.\n
